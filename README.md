# Partner BVA

A single self-contained page. What putting the dbt platform and Fivetran in front of a
client is worth, on both sides: services revenue to a partner, and budget and capacity to
their client.

This repository holds the built page and nothing else. It is generated, so do not edit it
here: changes are made in the source repository and republished.

Not a quote, not a forecast, and no customer names. Ranges come from delivered dbt Labs
business value assessments and from IDC research commissioned by dbt Labs.
